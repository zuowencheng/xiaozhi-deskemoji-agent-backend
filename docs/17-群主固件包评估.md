| 项 | 内容 |
|---|---|
| 顶层目录名 | `xiaozhi-deskemoji-gesture-music-taibai-main/` |

> 初次比对时显示 640 个文件"不同"，实为 **CRLF/LF 行尾差异**（GitHub 下载的 zip 是 LF，本地 clone 被转成了 CRLF）。归一化后差异瞬间收敛到 3 处源码。

### 3.2 依赖级

47 个托管组件版本 **100% 一致**（`78/xiaozhi-fonts 1.5.5`、`lvgl/lvgl 9.3.0`、`espressif/esp-sr 2.1.5`…）。
唯一差别：

| 组件 | zip（群主） | 本地 |
|---|---|---|
| `idf` | **5.5.1** | 5.5.4 |

→ 群主是在 IDF v5.5.1 上编的，我们是 v5.5.4。同一大版本，**编译产物互通，无兼容风险**。

## 四、3 处源码差异（逐条）

### ① `main/timer_manager.cc` —— 本地版更新（修了格式告警）

```c
// zip（群主原版）
ESP_LOGI(TAG, "... Duration: %u ms", name.c_str(), task.id.c_str(), duration_ms);
ESP_LOGI(TAG, "... Time: %ld", name.c_str(), task.id.c_str(), scheduled_time);

// 本地（已修）
#include <inttypes.h>
ESP_LOGI(TAG, "... Duration: %" PRIu32 " ms", ...);
ESP_LOGI(TAG, "... Time: %" PRId64, ..., (int64_t)scheduled_time);
```

`%u` / `%ld` 配 32/64 位整型在新版 GCC 下会报 `-Wformat`。本地版是**修过的**。

### ② `main/boards/esp32-s3n16r8-emoji/emoji_controller.h` —— 本地版多了声明

| 项 | zip（群主） | 本地 |
|---|---|---|
| `bool EnsureEmojiScreenActive();` | 无 | **有**（第 96 行） |
| `random_animation_enabled_` | `= true` | `= false` |

注：`EnsureEmojiScreenActive()` 目前**只有声明、没有定义**（全仓库 grep 只有 .h 一行），属于预留；不影响编译。`random_animation_enabled_ = false` 让随机眨眼/动画默认关闭，可由 `SetRandomAnimationEnabled()` 打开（.cc 第 613 行）。

### ③ `main/boards/esp32-s3n16r8-emoji-bak/board_config.h` —— 本地版启用了手势

```c
// zip 的 -bak：手势宏被整段注释掉
// // 手势识别模块配置
// #define GESTURE_I2C_SDA_PIN GPIO_NUM_41
...
// 本地：已启用
#define GESTURE_I2C_SDA_PIN GPIO_NUM_41
```

→ **这解释了那份救砖镜像为什么不含手势功能**：它是用"手势关闭"的 -bak 配置编译的。

### ④ 构建产物差异（不算代码差异）

`dependencies.lock`、`sdkconfig`、`sdkconfig.defaults`、`lang_config.h` —— 都是本地在 Stage A 构建/定制时产生的：
- 本地 `sdkconfig.defaults` 追加了自建后台覆盖块：
  ```
  CONFIG_OTA_URL="http://192.168.3.139:8003/xiaozhi/ota/"
  CONFIG_BOARD_TYPE_ESP32_S3N16R8_EMOJI=y
  ```
- 群主 `sdkconfig` 里 `CONFIG_OTA_URL="https://api.tenclass.net/xiaozhi/ota/"`（官方云）
- 本地 `main/assets/lang_config.h` 被我们改成了 `zh-CN`（fork 原版是 `vi-VN` 越南语 + en-US 回退）

## 五、唯一的真·新增资产：`merged-binary.bin`

| 项 | 值 |
|---|---|
| 体积 | 3,793,552 B (3.79 MB) |

| app 描述偏移 | `0x100020` |
| 版本号 | **2.0.1** |
| 编译时间 | **2025-11-18 10:56:03** |
| 编译 IDF | **v5.5.1** |
| 内嵌 OTA | `https://api.tenclass.net/xiaozhi/ota/`（官方云） |
| 附带 URL | `http://http-embedded-music.miao-lab.top:2233`（喵音乐服务器）、`http://192.168.4.1`（配网热点） |
| 板型配置 | `-bak`（**手势功能关闭**） |

**用途定位**：这是一份"**一键烧录整包**"，可在设备变砖时 `esptool write_flash 0x0 merged-binary.bin` 救回来。

**⚠️ 注意事项**：
1. 它是**官方云版本**，刷下去会**丢掉自建后台配置**（回到 xiaozhi.me）；
2. 它**不含手势功能**（-bak 配置）；
3. 它是 **2025-11 的老构建**，比我们手上的源码旧；
4. 版本号同样是 2.0.1 —— **不能靠版本号区分它和我们编的固件**，刷之前务必确认目标。
