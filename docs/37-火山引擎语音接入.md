# 火山引擎语音接入（2026-10-03）

## 一、结论先行：你给的 AK/SK 用不了语音合成

你给的是 **IAM 访问密钥**（AccessKeyID / SecretAccessKey）。实测：

| 验证项 | 结果 |
|---|---|
| AK/SK 签名有效性（IAM ListUsers） | ✅ HTTP 200，是本账号真实密钥 |
| 用 AK/SK 走 OpenAPI 网关调语音合成 | ❌ `ServiceNotFound: This service[tts] not found` |
| `tts.volcengineapi.com` | ❌ 域名都不存在 |

**火山引擎语音合成不走 OpenAPI 网关**，它用的是独立的 `openspeech.bytedance.com`，
鉴权是**语音技术控制台创建应用后发的 `appid` + `access_token`**，跟 IAM 的 AK/SK 完全是两套。

### 你还差一步（1 分钟）

1. 打开 https://console.volcengine.com/speech/app → 创建应用 → 拿到 **APPID** 和 **AccessToken**
2. 开通「大模型语音合成」+ 湾湾小何音色：https://console.volcengine.com/speech/service/10007
3. 把这两个值给我（或直接跑）：
   ```bash
   python tools/set_volc_tts.py <appid> <access_token>
   python tools/start_services.py --stop && python tools/start_services.py --explorer --wait 30
   ```

配置已就位（`data/.config.yaml` 里的 `HuoshanDoubleStreamTTS`），只等填凭据。
`tools/set_volc_tts.py` 会自动填凭据 + 把 `selected_module.TTS` 切过去，`--revert` 可回滚到 Edge。

## 四、20 块钱能用多久

按**大模型语音合成 5 元/万字符**（湾湾小何属此档），加 5 万免费字符：

```
20 元 ÷ 5 元/万字符 = 4 万字符
+ 免费额度 5 万字符
= 约 9 万字符
```

换算成实际使用（一句回复平均 30 字符）：

| 场景 | 估算 |
|---|---|
| 纯主动播报（短句 20 字） | ~4500 句 |
| 日常对话（每轮回复 40 字） | ~2200 轮 |
| 一天 100 句 | **约 3 个月** |
| 一天 300 句 + 主动播报 | 约 1 个月 |

如果换**豆包语音合成 2.0（3 元/万字符）**，同样 20 元能多 60%，约 11.7 万字符。

⚠️ 省钱提示：主动播报尽量短（已限制 ≤90 字），长文本播报很费钱。

但合成请求一律失败：

### 已排除的可能

| 猜测 | 验证 | 结论 |
|---|---|---|
| 凭据填错 / 顺序反了 | 交换 appid↔token 再试 | ❌ 同样报错 |
| cluster 不对 | 试 `volcano_tts` / `volcano_tts_streaming` / `volc_tts` / `tts` | ❌ 同样报错 |
| 只是音色没买 | 用最基础的 `BV001_streaming` 试 | ❌ 同样报错 |

→ **不是凭据问题，是这个应用没有语音合成的授权（grant）**。
注意：**账户充值 ≠ 开通服务**，充的 20 块只是账户余额。

### 还差的操作（控制台）

1. 打开 https://console.volcengine.com/speech/service/10007 → **开通「大模型语音合成」**
2. 页面里的音色列表 → 把「**湾湾小何**」加入（免费的也要领）
3. 官方说明：开通/领音色后**可能要等约 30 分钟**才生效

### 生效后自检

```bash
cd server/xiaozhi-server
python ../../tools/probe_volc.py tts
```
