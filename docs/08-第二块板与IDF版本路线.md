# 08 · 附件解析：第二块板是 ESP32-WROOM-32（经典款）

> 附件：`SG-234 ESp32基础实训（进阶版套餐）.docx`（生产规范书 / 配料清单）
> 解析日期：2026-10-02

## 一、这块板到底是什么

清单第 1 项就是答案：

| 序号 | 名称、型号 | 数量 | 编码 |
|---|---|---|---|
| 1 | **ESP32-WROOM-32 开发板** | 1 | C3-4-3L |

**ESP32-WROOM-32 = ESP32 经典款（Xtensa LX6 双核 240MHz）**，不是 S3、不是 C3。这一条直接改变了"第二块板能不能上小智"的答案。

关键规格（WROOM-32 模组标准配置）：

| 项 | 值 | 对小智的影响 |
|---|---|---|
| 芯片 | ESP32（经典款） | 官方芯片支持列表里有它 ✅ |
| Flash | 4 MB | 够用（小智双 OTA 分区约需 4MB 出头，偏紧） |
| PSRAM | **无** | ⚠️ 最大短板：跑不了重显示/大缓存的功能 |
| 内部 SRAM | ~520 KB | 音频缓冲＋协议栈后余量不多 |

### 清单全貌（36 项，节选与"上小智"相关的）

| 有 | 用途 |
|---|---|
| ESP32-WROOM-32 开发板 ×1 | 主控 |
| MAX98357 紫板 I2S 功放（焊好排针） | **音频输出**，正好是小智要的 |
| 0.96 寸 OLED（4 脚） | 小智 `bread-compact-esp32` 默认就配 SSD1306 |
| 1.54 寸 240×240 彩屏、LCD1602、8×8 点阵、4位/1位数码管 | 显示类，可选 |
| HC-SR04、HC-SR501、舵机、步进电机、摇杆、矩阵键盘、各类传感器 | 外设/做课程实验 |

**缺的两件（上小智必须补）：**
1. **麦克风**——清单里没有 INMP441 / ICS-43434 这类 I2S 数字麦，小智没麦就是哑巴。需另买（约 ¥8~15）。
2. **喇叭**——只有功放板（MAX98357），没有扬声器单元。需另买小喇叭（8Ω 1W~2W，约 ¥5）。

## 二、官方固件支持不支持它？支持

实测官方仓库 `main/boards/` 下有现成板型：

```
boards/bread-compact-esp32/config.json
{
  "type": "bread-compact-esp32",
  "target": "esp32",          ← 目标就是经典 ESP32
  "builds": [ "bread-compact-esp32", "bread-compact-esp32-128x32" ]
}
```

同类还有 `bread-compact-esp32-lcd`、`bread-compact-wifi`、`bread-compact-wifi-lcd` 等（`main/boards` 共 49 个板型目录）。

**结论：官方版给经典 ESP32 留了正规位置；社区版（单板 fork）则完全没有。**

这进一步加固了《07-固件主干选型评估》的结论——**官方版当主干**。原来理由是"多板子好扩展"，现在多了一条更硬的：**你那块 WROOM-32 官方能直接编译，社区版根本没这条路。**

### 但要认的限制（无 PSRAM）
- 只能走 `bread-compact-esp32` 这种"紧凑型"配置：**OLED 小屏 + 麦克风 + 功放**，不要指望上彩屏/emoji 表情/摄像头。
- 离线唤醒词（ESP-SR）在无 PSRAM 的经典 ESP32 上很吃紧，实际大概率要用**按键/音量触发**方案。
- 结论：这块板适合当**"第二台小智"练手/做实验**，主战场仍是 deskemoji 那块 S3N16R8（16MB Flash + 8MB PSRAM）。

## 三、⚠️ IDF 版本路线要修正（重要）

上一版计划里我写的是"锁 v5.5.4，别碰 v6"。**这个判断需要更正**——它是基于"跟你板子上 2.0.1 固件（IDF 5.5.1）对齐"的前提，但前提变了：既然主干换成官方版，就得看官方版的真实门槛。

实测官方各版本说明：

| 官方版本 | 发布日期 | 要求的 ESP-IDF |
|---|---|---|
| v2.2.6 | 2026-04-19 | 5.x 时代（README 未标注 6.x 门槛） |
| v2.4.2 | 2026-08-06 | 主线转向 **IDF v6.0+**，首选 v6.0.2；v5.5 仅保留给"老板型" |
| **v2.5.0（最新）** | 2026-09-10 | **最低 v6.0.1，推荐 v6.1；不再支持 IDF 5.x** |

也就是说：**想用最新官方版，就必须 IDF 6.1；IDF 5.5.4 只能编到官方 v2.2.x～v2.4 之前。**

### 建议：两段走，两个 IDF 都留着（EIM 支持多版本共存）

**Stage A（零风险，先跑通）**：用 **IDF v5.5.4** 编**社区那版固件**
- 目的：验证工具链、复现出跟你现在板子上一样的固件，把"编译→刷机→回滚"这条路走通
- 产物可对照，出问题 `rollback_app.cmd` 十秒回滚

**Stage B（主干）**：用 **IDF v6.1** 编**官方 v2.5.0 + 移植后的 deskemoji 板型**
- 这是长期的唯一主干；以后每块新板子（含 WROOM-32）都往上加目录
