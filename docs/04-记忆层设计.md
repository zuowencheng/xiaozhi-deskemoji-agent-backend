# 04 · 记忆层设计（本机 SQLite + 本地向量，数据不出网）

> 对应需求 C 组：五类记忆全要、本机 SQLite、要向量检索。

## 为什么不装 chromadb / faiss

一句话：**没必要，而且会毁掉"数据不出网"这条底线**。

| 方案 | 依赖 | 数据出网 | 结论 |
|---|---|---|---|
| chromadb + 云端嵌入 | 重（几百 MB） | ❌ 出网 | 否定 |
| chromadb + 本地模型 | 重 | 不出网 | 杀鸡用牛刀 |
| **SQLite + Ollama 本地嵌入** | **零新增依赖**（都用标准库） | ✅ 不出网 | **采用** |

本机恰好已经装了 Ollama（127.0.0.1:11434），里面有 `nomic-embed-text` 和 `qwen3:4b`。所以整套记忆层只用到 `sqlite3` + `urllib`，装都不用装。

## 架构

```
bridge/memory.py
├── 存储  bridge/memory/memory.db（SQLite）
│         ├── memories 表：id / ts / kind / content / tags / embed(BLOB)
│         └── memories_fts：FTS5 trigram 全文索引（辅助）
├── 向量  Ollama 本地嵌入，余弦相似度（纯 Python 算，条目少够快）
├── 检索  向量分 与 关键词分取最大（向量优先，关键词兜底）
└── 降级  Ollama 挂了自动退化为纯关键词检索，绝不阻塞语音
```

五类记忆（`kind`）：`chat` 对话 / `profile` 用户画像 / `project` 项目上下文 / `knowledge` 知识库 / `task` 任务记忆。

## 实测：换模型这一步是质变

同一批 4 条记忆，同一组问题，两个模型对比：

| 问题 | nomic-embed-text 第一条 | bge-m3 第一条 |
|---|---|---|
| 固件升级有风险吗 | ❌ 隐私偏好（完全跑偏） | ✅ 固件/ota 分区知识 |
| 板子有多大存储空间 | ❌ 隐私偏好 | ✅ 固件/16MB 知识 |
| 主人有什么习惯 | ✅ 隐私偏好 | ✅ 隐私偏好 |

**结论：nomic-embed-text 的中文短句相似度全挤在 0.5~0.8，区分度不够，会张冠李戴。bge-m3 才是对的。** 模型优先级写死在 `memory.py` 的 `_MODEL_PREFERENCE = ("bge-m3", "nomic-embed-text")`，也可用环境变量 `XZ_EMBED_MODEL` 覆盖。

性能（模型热了之后）：**单次检索 0.1 秒**，写入约 1 秒/条。

## 踩过的三个坑（都写进代码注释了）

1. **冷启动超时导致"半残"记忆库**：nomic 首次加载要 10~20 秒，原来 8 秒超时会静默失败 → 表现为 4 条里只有 2 条有向量。现在超时 25 秒 + 重试 1 次 + `keep_alive: 10m` 常驻，另加 `warmup()` 在桥启动时后台预热。
2. **FTS5 trigram 对中文整句漏召回**：查"固件升级有风险吗"整句 MATCH 不到含"固件"的条目。改成 Python 侧算 **2-gram 重合率**做关键词兜底，中文比 FTS 更靠谱。
3. **换嵌入模型必须 reindex**：不同模型的向量空间不通用，混着比等于拿两把不同刻度的尺子量长度。命令 `python memory.py reindex`。

## 用法

```bash
python memory.py recent            # 看最近 10 条
python memory.py search 固件升级    # 语义检索
python memory.py stats             # 统计（含当前嵌入模型）
python memory.py reindex           # 换模型后重建向量
python memory.py backfill          # 补回填漏掉的向量
python memory.py warmup            # 预热模型
```

语音侧四个工具：`remember`（记）、`recall`（查）、`list_memories`（列）、`forget`（删）。
另外 `dispatch_agent` 会自动把派出去的任务记成 `task` 类记忆。

## 隐私

- 记忆库 `bridge/memory/` 已加入 `.gitignore`，**不进仓库**
- 嵌入计算全在本机 Ollama，**文本不出网**
- 云端大模型只会拿到 `recall` 返回的检索结果片段（这是必然的，否则它没法回答）
