# 配置指南（必读）

> 这份文档回答一个问题：**跑起小智后台，我需要准备哪些 Key？要不要下模型？去哪配？**
>
> 原则：**本项目不附带任何真实 Key、也不附带大模型权重**。你按需申请、按需下载，全部填在本地，不上传。

---

## 一、先选运行模式

小智后台的「语音识别（ASR）」「对话（LLM）」「语音合成（TTS）」都可以**本地**或**云端**二选一。按你的隐私要求 / 有没有 GPU / 愿不愿意花钱，选一种：

| 模式 | 组合 | 要申请的 Key | 要不要下模型 | 适合谁 |
|---|---|---|---|---|
| **A. 全云端（最省事）** | 火山 ASR + DeepSeek/豆包 LLM + EdgeTTS | 1～2 个 | ❌ 不用 | 只想快速跑起来 |
| **B. 全本地（最隐私）** | Sherpa ASR + Ollama LLM + 本地 TTS | ❌ 零 Key | ✅ 要下（约 3 GB） | 数据不出网、有台还行的电脑 |
| **C. 混合（推荐）** | Sherpa ASR（本地） + DeepSeek（云端） | 1 个 | ✅ 要下（约 1 GB） | 语音本地、对话借云端智力 |

> 咱们这台机器现在跑的是 **模式 C**（识别本地、对话走云端、合成走微软免费 EdgeTTS）。

## 二、Key 清单：需要哪些、去哪申请、填在哪

全部填在 `server/xiaozhi-server/data/.config.yaml`（从 `server/config.example.yaml` 复制而来）。

| # | 用途 | 配置字段 | 强制? | 申请地址 | 备注 |
|---|---|---|---|---|---|
| 1 | **对话 LLM** | `LLM.DoubaoLLM.api_key` | 用云端 LLM 时**必需** | https://platform.deepseek.com/ 或 https://console.volcengine.com/ | DeepSeek 便宜，豆包有免费额度 |
| 2 | **语音识别 ASR** | `ASR.DoubaoASR.appid` + `access_token` | 用云端 ASR 时必需 | https://console.volcengine.com/ （语音技术） | 用 SherpaASR 则免 |
| 3 | **语音合成 TTS** | `TTS.*.appid` + `access_token` | 默认**不需要** | https://console.volcengine.com/ | 默认 EdgeTTS，**免费且免 Key** |
| 4 | 天气插件 | `plugins.Weather.api_key` | 可选 | https://dev.qweather.com/ | 和风天气，免费额度够用 |
| 5 | 联网搜索 | `plugins.*.api_key`（Tavily） | 可选 | https://tavily.com/ | 不填则搜索插件不可用 |
| 6 | 云端记忆 | `Memory.mem0ai.api_key` | 可选 | https://app.mem0.ai/ | 记忆本地已由 `bridge/memory.py` 承担，可不填 |
| 7 | MCP 接入点 | `mcp_endpoint` | 可选 | https://xiaozhi.me/ | 用本机桥才需要，自建回执后可删 |
| 8 | 设备鉴权 | `server.auth.allowed_devices` | 可选 | — | 填你的设备 MAC，局域网自用可关鉴权 |

**最小可用配置**：只填 **#1（LLM）**，其他用默认（本地 VAD + EdgeTTS）就能跑起来。

## 三、本地大模型：可选清单（只给链接，需自行下载）

> 我们**不打包**模型权重（太大），按需自取。下载后放到指定目录即可。

| 模块 | 推荐模型 | 体积 | 下载地址 | 放哪 |
|---|---|---|---|---|
| **VAD**（语音端点检测） | Silero VAD | ~2 MB | https://github.com/snakers4/silero-vad | `models/snakers4_silero-vad/` |
| **ASR**（本地识别） | Sherpa-onnx SenseVoice Small | ~1 GB | https://www.modelscope.cn/models/pkufool/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17 （或 https://huggingface.co/csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17 ） | `models/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17/` |
| **LLM**（本地对话） | Ollama + `qwen3:4b` | ~2.5 GB | https://ollama.com/download 装完执行 `ollama pull qwen3:4b` | 由 Ollama 自管 |
| LLM 备选 | ChatGLM / Qwen 系列 | — | https://www.modelscope.cn/ | — |

配置里怎么切：

```yaml
selected_module:
  ASR: SherpaASR     # 改这条 → 用本地识别（需下 SenseVoice）
  LLM: OllamaLLM     # 改这条 → 用本机 Ollama
```

> 💡 模型下载总站：[ModelScope（国内快）](https://www.modelscope.cn/) / [HuggingFace](https://huggingface.co/)。
> 具体下载脚本可参考仓库里的 `tools/fetch_sherpa_model.py`。

## 四、配置三步走

```bash
# 1. 复制模板
copy server\config.example.yaml server\xiaozhi-server\data\.config.yaml

# 2. 编辑 .config.yaml，按第二节的表填 Key、按需选本地/云端
#    ⚠️ 这个文件已被 .gitignore 排除，填了真 Key 也不会进仓库

# 3. 启动
双击 server\start_server.cmd
```

启动成功的标志：

```
Websocket地址是   ws://192.168.x.x:8000/xiaozhi/v1/
OTA接口是         http://192.168.x.x:8003/xiaozhi/ota/
```

## 五、安全提醒（重要）

1. **真 Key 只填 `data/.config.yaml`** —— 该目录已被 gitignore，不会被提交。
2. **不要**把 Key 填进 `server/xiaozhi-server/config.yaml` —— 那个文件**是进仓库的**，仓库里的必须以占位符（`你的xxx`）形式存在。
3. 提交前自查：
   ```bash
   git ls-files | findstr config.yaml    :: 确认列出的都是模板
   git grep -iE "sk-[A-Za-z0-9]{16}|tvly-|appid: [0-9a-f-]{36}"  :: 查有没有漏网的真 Key
   ```
4. 设备 IP 变了要重配：设备端固件里写的是 `ws://<本机IP>:8000/xiaozhi/v1/`，换网络后需在设备配网时更新。

## 六、配置项速查（`config.example.yaml` 已标注释）

| 段 | 关键项 | 说明 |
|---|---|---|
| `server` | `port` / `http_port` / `auth` | 8000 WS、8003 OTA+视觉、8004 播报、8005 管理台 |
| `selected_module` | `VAD` / `ASR` / `LLM` / `TTS` / `Memory` | 选本地还是云端 |
| `ASR` / `LLM` / `TTS` | 各自的连接参数 | 见第二节 |
| `mcp_endpoint` | 本机桥地址 | 自建回执完成后可删 |
