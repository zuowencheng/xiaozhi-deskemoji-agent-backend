## 四、管理台（本轮新增，已跑通）

### 4.1 为什么自己写

- 上游没有页面（§1.7）
- 官方智控台要 Java 21 + MySQL + Redis，本机没 Docker，装下来比整个项目还重
- 我们要的其实只有：**看状态 + 改几个开关 + 启停服务**

所以用**纯 Python 标准库**写了一个单文件管理台 —— 零新依赖，跟上游源码完全隔离（升级上游不受影响）。

### 4.2 文件

```
server/admin/
├── admin_server.py          管理台本体（纯标准库，单文件）
├── start_admin.cmd          双击启动（UTF-8 + CRLF）
├── autostart_on.cmd         安装开机自启
├── autostart_off.cmd        取消开机自启
├── _admin_autostart.vbs     开机静默启动器（由上面那个复制到启动文件夹）
└── _make_scripts.py         生成上述脚本（保证编码与行尾正确）
```

### 4.3 功能

| 模块 | 内容 |
|---|---|
| **服务状态** | 8000/8003/8004/11434 端口存活 + 占用 PID，一键启动/停止后台 |
| **设备** | 在线设备列表（查 8004 `/notify/status`） |
| **配置** | 17 个白名单开关做成表单，保存即写回 `.config.yaml` |
| **投递箱** | `inbox/` 待办、`done/` 已完成的任务列表 |
| **日志** | 服务日志与错误日志尾部 |

### 4.4 安全设计（配置写坏 = 后台起不来，所以加了五道保险）

1. **白名单**：只有上面 23 项可改，其他一律拒绝
2. **类型校验**：整数/布尔/枚举，非法值跳过并把原因回显
3. **YAML 校验**：写入前先 `yaml.safe_load`，不合法直接拒绝
4. **自动备份**：每次写入前存一份 `.config.yaml.bak-<时间戳>`
5. （额外）**保留行尾注释**：只替换"值"那一截，说明文字不动 —— 这点一开始没做对，
   导致带注释的行被当成"键不存在"而在文件末尾追加了重复键，已修复并做了幂等性测试

### 4.5 怎么用

```
双击  server/admin/start_admin.cmd
浏览器打开  http://127.0.0.1:8005
```

想开机自动跑：

```
双击  server/admin/autostart_on.cmd     ← 安装（往"启动"文件夹放一个 .vbs）
双击  server/admin/autostart_off.cmd    ← 取消
```

## 五、"能否后台跑"—— 这个问题的正解

### 5.1 为什么之前后台老是消失

**实测（本轮）**：17:39 发现 8000/8003/8004/11434 **全部消失**。
根因：**AI 会话里拉起的进程，会话结束就被整棵回收**——即使用 `DETACHED_PROCESS |
CREATE_NEW_PROCESS_GROUP | CREATE_BREAKAWAY_FROM_JOB` 全上也没用。
（这条已经写进 `stackchan-workbuddy-bridge` 技能的"三条红线"里了。）

### 5.2 为什么"管理台"能解决

**本进程由你启动 → 它拉起的子进程不会被回收。**

所以正确姿势是：**你只启动"管理台"这一个东西，其他的由它托管。**

```
你双击 start_admin.cmd（或开机自启）
   └─ 管理台（8005）
        ├─ 自动拉起 xiaozhi-server（8000/8003/8004）  ← 用 DETACHED_PROCESS 起，独立存活
        ├─ 提供配置/状态/任务页面
        └─ 页面上一键重启后台
```

### 5.3 开机自启不需要管理员权限

用的是**"启动"文件夹**（`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`），
把 `_admin_autostart.vbs` 复制进去即可 —— 不碰计划任务、不碰注册表、不要管理员。

`.vbs` 用 `Run(..., 0, False)` 启动，**没有任何窗口**，就是你要的"后台跑"。
