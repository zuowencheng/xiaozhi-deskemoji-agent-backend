## ④ 提示音换柔和版 ✅（已换上 A，需要你听）

**根因**：原来的 `popup.ogg` 是 **480ms**——对提示音来说太长，所以听着"呲"。

**已做**：
- 生成 880+1320Hz / **200ms** 双音（指数衰减 + 8ms 淡入淡出防爆音）
- 覆盖 `firmware/community/main/assets/common/popup.ogg`
- **原文件已备份**：`popup.ogg.bak-480ms`（3801 字节 → 1148 字节）
- 已编译刷机

**为什么选 200ms**：这块板子**无 AEC**（0 回放通道），提示音会被麦克风录进去。
**越短越不容易干扰识别**——这是硬约束，不是审美问题。
