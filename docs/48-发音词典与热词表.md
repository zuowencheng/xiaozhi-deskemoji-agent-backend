1. 火山控制台 → **自学习平台 → 热词管理 → 新建热词表**
   （或直接进 https://console.volcengine.com/speech/ → 自学习平台）
2. 打开 `bridge/hotwords.txt`，**全选复制**，粘贴进去
3. 保存 → 拿到一个 **UUID**
4. 填到配置：
   ```yaml
   # data/.config.yaml → ASR.DoubaoStreamASRStream
   boosting_table_name: "把那个 UUID 填这里"
   ```
5. 重启后台，ASR 切到 `DoubaoASRStream` 生效

### 权重设置建议

火山支持 `词|数字` 设权重 1~10（不写默认 4）。建议：

| 词 | 权重 | 原因 |
|---|---|---|
| `deskemoji` | 8 | 英文混中文，本地实测认成 disimmoji |
| `WorkBuddy` | 8 | 英文专名，被拆成 work bud |
| `舵机` | 8 | 同音字（多机） |
| `小智` | 7 | 高频但不难念 |
| 日常高频词 | 4 | 默认即可 |

**只加专有名词就够，别把普通词都塞进去**——热词太多会互相干扰。
