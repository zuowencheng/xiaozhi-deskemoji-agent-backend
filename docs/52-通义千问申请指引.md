> 2026-10-03 整理。给 `qwen-plus` 当**云端备选大脑**用（DeepSeek 挂了/想换口味时切换）。
> 现有配置位置：`server/xiaozhi-server/data/.config.yaml` 的 `llm_profiles.QwenLLM`

| | DeepSeek（现有） | 通义千问（新增） |

| 免费额度 | 按 token 计，目前够用 | **新用户 7000 万 tokens，90 天有效** |

| 国内网络 | 稳 | **阿里云，国内直连更快** |
| 定位 | 主力 | **备份**（主力挂了自动顶上） |

## 二、申请步骤（5 分钟）

### 1️⃣ 注册 / 登录阿里云
👉 https://bailian.console.aliyun.com/

用**支付宝**或阿里云账号登录。没有就现注册一个。

### 2️⃣ 实名认证（**这一步不能跳**）
控制台会提示「您尚未进行实名认证」——**不做实名认证就没有免费额度**。
阿里云 App 刷脸，1~2 分钟。

### 3️⃣ 开通百炼
读并同意服务协议 → **自动开通**，同时发放免费额度。
（没弹协议 = 早就开过了）

### 4️⃣ 创建 API Key
👉 https://bailian.console.aliyun.com/?apiKey=1

点「创建 API Key」→ 复制保存（`sk-` 开头，形如 `sk-xxxxxxxx`）。

> ⚠️ **创建时不用选模型**，调用时用请求体的 `model` 参数指定。
> 如果想限制这把 key 只能调某些模型，勾「自定义权限」。

---

## 三、填到小智配置里

打开 `server/xiaozhi-server/data/.config.yaml`，找到：

```yaml
llm_profiles:
  QwenLLM:
    api_key: "sk-填你的通义千问key"    # ← 把这行换掉
    model_name: qwen-plus               # ← 保持这个
    base_url: https://dashscope.aliyuncs.com/compatible-mode/v1
```

或者直接跟小智说「**把大脑切到通义千问**」，我帮你填。

---

## 四、选哪个模型

| 模型 | 价格（每百万 token） | 适合 |
|---|---|---|
| **`qwen-plus`** ⭐ | 输入 ¥0.8 / 输出 ¥2 | **性价比最高，推荐先用这个** |
| `qwen-turbo` | 输入 ¥0.3 | 最便宜，但简单任务够用 |
| `qwen-max` | 输入 ¥2.4 / 输出 ¥9.6 | 最强，也最贵 |

> ⚠️ 我配置里默认写的是 **`qwen-plus`**（平衡点）。
> 阿里云模型广场还有 Qwen3.6/3.7 系列（更贵但更强），
> 名字形如 `qwen3.7-plus`，要用的话把 `model_name` 改成它即可。

## 五、坑（官方文档 + 实测确认）

| 坑 | 说明 |
|---|---|
| **免费额度只在北京地域** | 必须选**华北2（北京）**，其他地域不享受免费额度 |
| **Token Plan 的 key 不扣免费额度** | 反过来说：用**普通 key** 才会消耗免费包，别搞反 |
| **免费额度 90 天有效** | 从开通起算，到期不补不延期；同实名主体重新注册也领不到第二次 |
| **创建 key 不用选模型** | 选不选都不影响调用，别在这纠结 |
| **用了北京地域要填 WorkspaceId** | 只在使用特定业务空间时需要，个人用一般不用管 |

---

## 六、超额防护（建议开）

在百炼控制台开「**免费额度用完即停**」，避免用超了直接扣钱。
通义千问本身很便宜（`qwen-turbo` 输入才 ¥0.3/百万），但加上这个开关更稳。

---

## 七、验证是否配好

跟小智说「**把大脑切到通义千问**」，然后听它说话。
或者跑自检：

```bash
python tools/selftest.py --only 大模型
```

配置生效后，管理台「大模型」卡片会显示 `key 就绪`。
