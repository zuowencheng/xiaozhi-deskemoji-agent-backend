# 11 · 第二台小智：采购清单 + 官方默认接线表

> 目标：**不再买 ESP32 板子**，用手头 WROOM-32 套装 + 补两件小件，组装出第二台小智。

> 日期：2026-10-02 ｜ 引脚来自官方 v2.5.0 `main/boards/bread-compact-esp32*/config.h` 实读

> 说明：上面前两个是**搜索词直达链接**（商品页会随店铺上下架变动，我给你的搜索词是精准的，点进去挑即可）；第三个是立创的真实商品页，但那是**裸芯片**，要自己焊，你走面包板就买**模块**。
> 老牌元器件店（天猫 telesky 旗舰店、泽杰旗舰店这类）都有，券后大约 **¥7~12**。

**✅ 验收要点（下单前对着看）**
- 必须是**模块**：小 PCB + **已焊好排针**（不然你还得焊，面包板插不进去）
- 引脚 **6 个**：`VDD / GND / L-R / WS / SCK / SD`
- 供电 **3.3V**（⚠️ **绝对不能接 5V**，会烧）
- 别买错型号：
  - ❌ **MAX4466 / MAX9814** —— 这是**模拟**麦，要 ADC，小智固件不支持
  - ❌ **MP34DT01 / SPH0645** —— **PDM** 接口，不是标准 I2S，小智不认
  - ✅ 想升级可以选 **ICS-43434** 模块（信噪比更高），但很贵（¥25+）且货少，第一台没必要

**可用的搜索词**：`腔体喇叭 8欧2W`、`8Ω2W 带腔体 3020`、`腔体喇叭 40mm 8欧`

**✅ 验收要点**
- **阻抗/功率**：4Ω 3W 或 8Ω 1~2W 都可以（4Ω 更响）；**8Ω 2W 最通用**
- **一定要带腔体**（封闭音腔）——不带腔体的裸喇叭，声音又小又薄，差一个量级，差价就几块钱
- 直径 **28~40mm** 都行
- 接口优先选**带 2.54mm 排针 或 PH2.0 端子**的，别买只有两根细软线的（面包板上反复插会断）
- 预算 **¥5~15**

**⚠️ 这条必须记牢：喇叭绝对不能直接接 ESP32 引脚。**
必须经 **MAX98357 功放**驱动。直连会把 GPIO 烧掉——这是新手头号杀手，每年都有人踩。

## 二、接线表（照抄即可，不用改代码）

### 板型 A：`bread-compact-esp32`（配你那个 0.96" OLED）

**A-1. INMP441 麦克风 → ESP32**

| INMP441 | 接到 ESP32 | 说明 |
|---|---|---|
| VDD | **3.3V** | ⚠️ 不能接 5V |
| GND | **GND** | |
| L/R | **GND** | 接地 = 左声道（必须接，不能悬空） |
| WS | **GPIO25** | |
| SCK | **GPIO26** | |
| SD | **GPIO32** | |

**A-2. MAX98357 功放 → ESP32**

| MAX98357 | 接到 ESP32 | 说明 |
|---|---|---|
| VIN | **5V**（推荐） | 接 5V 比 3.3V 响得多；开发板 5V 脚从 USB 取电，够用 |
| GND | **GND** | |
| DIN | **GPIO33** | |
| BCLK | **GPIO14** | |
| LRC | **GPIO27** | |
| GAIN | 悬空 | 悬空=9dB；接 GND=15dB（最响）；接 VDD=3dB |
| SD | **3.3V** | 使能脚，高电平开启；接 GND 会静音 |
| 喇叭 + | 喇叭正极 | **接喇叭，不接 MCU** |
| 喇叭 − | 喇叭负极 | |

**A-3. 0.96" OLED（SSD1306，4 脚）→ ESP32**

| OLED | 接到 ESP32 |
|---|---|
| VCC | **3.3V** |
| GND | **GND** |
| SDA | **GPIO4** |
| SCL | **GPIO15** |

**A-4. 附加：板载 LED / 按键 / 继电器**

| 功能 | 引脚 |
|---|---|
| BOOT 按键 | **GPIO0** |
| ASR 触发按键 | **GPIO19** |
| 板载 LED | **GPIO2** |
| ⭐ **"控制台灯" MCP 示例（LAMP）** | **GPIO18** |

> 官方这块板型自带一个 **`LAMP_GPIO = GPIO18` 的 MCP 示例工具（Control a lamp）**——正好配你清单第 12 项那个**继电器模块**！接上就能对着小智说"帮我开灯"，不用改代码。这是本次最划算的一个发现。

### 板型 B：`bread-compact-esp32-lcd`（配你那个 1.54" 240×240 彩屏）

音频（INMP441 / MAX98357）的接线和上面 **A-1 / A-2 完全一样**，只把屏换掉：

| 1.54" ST7789 彩屏 | 接到 ESP32 | 说明 |
|---|---|---|
| VCC | **3.3V** | |
| GND | **GND** | |
| SCL / CLK | **GPIO15** | |
| SDA / MOSI | **GPIO4** | |
| RES / RST | **GPIO18** | |
| DC | **GPIO21** | |
| CS | **接 GND** | ⭐ 官方 7PIN 配置里 `DISPLAY_CS_PIN = GPIO_NUM_NC`（不用 CS）。你的模块是 8 针带 CS，**直接接地（一直选中）即可** |
| BLK / BL | **GPIO22** | 背光 |

**⚠️ 两块屏是二选一**：OLED 和彩屏用的是同一组引脚（GPIO4/15），不能同时接。一次只能刷一个板型。

## 三、你要不要自己买个开发板？

**不用买。** 手头的够：

| 已有 | 用途 |
|---|---|
| ESP32-WROOM-32 开发板 | 主控 |
| MAX98357 紫板（焊好排针） | 功放 ✅ |
| 0.96" OLED / 1.54" 彩屏 | 屏（二选一） |
| ESP32 扩展板 30P 黑板 | 直接插面包板，省一半杜邦线 |
| 830 孔面包板 + 120 根杜邦线 | 全用得上 |
| 蓝色 4 芯 micro-USB 线（清单第 9 项） | 如果开发板是 micro-USB 口，直接用（4 芯能传数据，但要实测确认不是纯充电线） |

**只补**：INMP441 模块 + 腔体喇叭，合计 **¥15~30**。

## 四、上电顺序（老规矩，别一次全插）

1. **先不上 USB**，把线接完，**对着表逐个复查一遍**（尤其 INMP441 的 VDD 是 3.3V 不是 5V、L/R 不能悬空）
2. 只接 OLED/彩屏 → 插 USB 刷机 → 看屏能不能亮、能不能显示
3. 断电，再接 INMP441 + MAX98357 + 喇叭 → 上电看串口日志有没有 I2S 报错
4. 最后配网、连你自己的后台（`ws://192.168.3.139:8000/xiaozhi/v1/`）

**要认的限制**：这块板**无 PSRAM**，离线唤醒词（ESP-SR）空间很紧，实践中更常用的是**按键触发**。官方这块板型能编能跑，但唤醒方式大概率要落到按键上——刷进去实测一下就知道，别一开始就期待"喊一声就醒"。
